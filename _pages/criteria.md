## General Guidelines

We apply these priorities when considering new recommendations:

* **Private:** Tools should prioritize privacy first. Not selling, sharing, or storing unnecessary user data.
* **Secure:** Tools should follow security best-practices wherever applicable.
* **Cross-Platform:** Tools should be available on as many platforms, including Linux, as possible. 
* **Active Development:** Tools that we recommend should be actively developed, unmaintained projects will be removed in most cases.
* **Usability:** Tools should be accessible to most computer users, an overly technical background should not be required. 
* **Encryption:** If encryption is offered, it should be on by default and not left to the user to activate.
